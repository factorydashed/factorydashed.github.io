Count

Counters and quick steps

Tap to count, with your own step, goal, limits, units, packs and decimals.

Display styles

A number, a bar, a ring, an icon fill or a row of the last seven days.

Variable amounts

A tap asks how much. Recent sizes are one tap away.

Set value

For a reading, like a weight. The tile shows the change since last time.

Reset periods and undo

Reset daily, weekly or monthly. Undo reverts the last action and what its rules did.

Start over

Reset a whole page for a game or a new day, in one undo.

Focus mode

One counter full screen, a big tap target, screen kept on.

Organize

Pages, tiles and edit mode

Group tiles on pages. Drag, resize and delete them.

Icons and colours

Every counter gets a colour and an optional icon.

Groups

Up to 8 counters in one tile, each with its goal bar.

Example pages

New installs get three pages that show what it can do.

Templates

Start from 13 ready-made pages: Water, Workout, Macros, D&D and more.

Your own templates

Save any page as a template on your device.

Share and import

Send a page as a link, QR code or file. Only the setup travels, never your counts.

Phones, foldables, tablets

Tabs on phones, a rail and side panes on bigger screens.

Timers

Stopwatch with laps, countdown with loops and alerts, and time-since.

Auto-count and reminders

Rule icons

Every tile shows whether rules watch it or change it.

Formulas

Widgets

Progress

Dice rules

Round tracker

Round number and turn order on one tile, up to 20 names.

Table mode
